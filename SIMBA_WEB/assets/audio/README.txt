PETUNJUK SOUND EFFECT SIMBA:
==============================
1. Anda dapat meletakkan file audio efek suara letusan di folder ini dengan nama:
   eruption.mp3

2. Format yang didukung: .mp3 atau .wav
3. Jika file 'eruption.mp3' tersedia di folder ini, SIMBA akan otomatis memutar file tersebut saat letusan terjadi!
4. Jika file belum dimasukkan, SIMBA otomatis menggunakan generator suara letusan sintetis internal (Web Audio API) tanpa error.
